# Agent Skills Wiki

High-signal, installable agent skills mined from X three times a day (08:00 / 14:00 / 20:00 Asia/Shanghai).
从 X 每天三次挖掘、人工筛过的 Agent Skills。

- **[Catalog](Catalog.md)** — every entry, newest first
- **[Digests](digests/)** — what each scan found, skipped, and is still watching
- **[Entries](entries/)** — one page per skill: When to use · What it does · Recipe / links · Why it made the cut

## Inclusion criteria / 收录标准

A skill = a multi-step recipe an agent can load, with a clear *when to use*, concrete steps, and ideally a shareable `SKILL.md` or repo. An entry meets at least two of:

1. Concrete recipe (steps / checklist / `SKILL.md`)
2. Clear use case
3. Verifiable material (repo, gist, long post)
4. Community signal (bonus only)

Skipped: ads, hype without steps, tutorials with nothing reusable, repeats.
