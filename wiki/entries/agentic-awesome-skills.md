## When to use
想给 Claude Code、Codex、Cursor、Gemini CLI 等批量找现成 `SKILL.md`，又不想「装一个试一个」：先让 Agent 在本地完整目录里检索、对比、预览，再决定装哪些。

## What it does
2,884+ 个可安装的 `SKILL.md` playbook，按 bundle / workflow 组织，带稳定的 skills manifest。配套的 **AAS Core** 让 Agent 自己检索本地目录、推荐并选择技能、校验技能组合、先出变更计划预览再动手（apply / recovery 仍为实验功能）。提供 CLI（`npx agentic-awesome-skills`）、MCP 和各工具插件安装方式。

## Recipe / links
- Repo: https://github.com/sickn33/agentic-awesome-skills

## Why it made the cut
虽然是大合集，但不只是列表：AAS Core 把「发现 → 选择 → 预览」做成 Agent 可执行流程，社区信号极强，多工具通用。注意合集质量参差，安装前仍应逐个读 `SKILL.md`（可配合 [SkillSpector](skillspector.md) 扫描）。
