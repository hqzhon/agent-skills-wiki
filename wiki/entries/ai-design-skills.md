## When to use
When you want an agent to **build a landing page from scratch with a real visual system**, or turn a static design into a **pixel-exact motion showcase** (MP4/GIF)—not another generic AI template.

## What it does
Open collection of design skills for Claude Code, Cursor, Codex, Windsurf, etc. Current skills: `landing-page-design` (intake → structure → conversion copy → type/spacing/radius/motion) and `design-to-motion` (static → looped animated showcase export). Related: standalone [redesign-skill](https://github.com/elayadesign/redesign-skill) for upgrading existing sites.

## Recipe / links
- Repo: https://github.com/elayadesign/ai-design-skills (~6074★)
- Claude Code: clone and `cp -r skills/<skill-name> .claude/skills/`
- Cursor: curl `SKILL.md` into `.cursor/rules/` or Rules for AI
- Ask in plain language for what that skill covers after install

## Why it made the cut
Installable SKILL.md pack, clear scenarios, strong community signal, and a public repo with documented install paths—distinct from Hallmark’s theme+lint approach.
