## When to use
When the user wants an **interactive isometric SVG/WebGL figure** that explains a technical idea as a physical machine—docs diagrams, “Linear-style” drawings, blog/landing explainers—even if they never say “isometric”.

## What it does
A large Claude-oriented agent skill (`SKILL.md` + `kit/`, examples, audits) that invents a recognisable bench instrument whose working *is* the concept: four-tone shading, painter’s order, framed card with live readout, optional WebGL (fire, water, caustics). Ships eight worked examples (dial gauge → Raptor engine) and A4 PDF / gallery publish paths.
