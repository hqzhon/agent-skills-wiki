# Animated Sticker Studio（动态表情包工坊）

**Tags:** sticker, gif, wechat, telegram, illustration, skill

## When to use
给一张角色图（或文字描述）要整套会动的聊天表情包，并按微信表情开放平台 / Telegram / LINE / Discord / Slack / WhatsApp 规格导出。不要用于单张静态 meme 或不要求平台合规体积的随便动图。

## What it does
根目录 `SKILL.md` + `scripts/`：plan → 参考图 → atlas → 切割 → 构建 → 自检 → 打包。支持真关键帧手势动画 + 程序化运动、22 种 motion preset、多平台尺寸/帧数/体积重编码直到过线。
