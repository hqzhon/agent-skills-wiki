## When to use
让 coding agent **在 Apify 上选 Actor 抓网页、写/部署 Actor、或把现有脚本 Actorize**，而不是手写脆弱爬虫。

## What it does
五件套：`apify-ultimate-scraper`（选 Actor / 跑任务 / 出结果）、`apify-actor-development`、`apify-actorization`、`apify-generate-output-schema`、`apify-integration-development`。覆盖社交/搜索/地图/点评等常用源，并可回落到 30k+ Actor Store。社区领域技能另见 `apify/awesome-skills`。
