## When to use
When an agent should design, review, or adapt Apple-platform UI (iPhone, Mac, Watch, TV, …) against Human Interface Guidelines—buttons, navigation, accessibility, privacy, modality—without stuffing the whole HIG into the prompt.

## What it does
Portable `apple-hig` router skill with 13 area subskills and 158 reviewed topic guides (Oct 2025 HIG snapshot). Routes only the relevant topics into context; includes coverage reports, CI validation, and install via Skills CLI. Independent community project (MIT), unaffiliated with Apple.

## Recipe / links
- Repo: https://github.com/AyushRajSinghParihar/apple-human-interface-skills (~6★)
