## When to use
When you need an **explorable standalone HTML diagram** (architecture, sequence, dataflow, ERD, timeline, etc.) from a description or a real codebase—or a one-page explainer answer—rather than a static screenshot.

## What it does
Agent skill `archify/SKILL.md` plus CLI (`bin/archify.mjs finalize …`) that validates candidates, delivers HTML with dark/light themes, and can source-back diagrams from a repo. Install: `npx skills add tt-a1i/archify -g`. Works with Claude Code, Codex, Cursor, OpenCode.
