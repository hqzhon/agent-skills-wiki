## When to use
When building a **game with an AI coding agent** (Godot, Unity, Unreal, Phaser, three.js, Bevy, Roblox, …)—art, animation, perf, Steam shipping—and you want the agent to load the right engine/task skill automatically.

## What it does
~76 version-pinned portable `SKILL.md` skills plus a **router** that detects engine/task and loads only what fits. Apache-2.0. Install once; works in Claude Code, Cursor, Codex, Copilot, Gemini CLI, and more.
