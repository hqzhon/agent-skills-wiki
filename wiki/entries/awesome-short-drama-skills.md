## When to use
When you need a **可安装的短剧 / 漫剧 Agent Skill 清单**（剧本、改编、分镜、Seedance / 可灵 / MiniMax 提示词等），或想先装清单自带的 finder skill，再让 agent 按场景推荐该装哪一个。

## What it does
Curated awesome list of AI short-drama / micro-drama / manju skills for Claude Code, Codex, OpenClaw, Qwen, Doubao, WorkBuddy, etc. Ships `skills/short-drama-skill-finder` plus taxonomy data; site at shortdramaskills.com. Community evals (same script × many skills) show wrong skill can beat “no skill”—so the finder matters.

## Recipe / links
- Repo: https://github.com/UnderleveledBuilder/awesome-short-drama-skills (~1.2k★, CC0-1.0)
- Install finder / listed packs: `npx skills add UnderleveledBuilder/awesome-short-drama-skills`
- Read each target `SKILL.md` (some include scripts) before granting shell/network
- Distinct from single-pipeline packs like [shuohao-skills](shuohao-skills.md)

## Why it made the cut
Verifiable curated skill library with install CLI, finder skill, and evidence that skill choice changes outcomes—not a single opaque “make short drama” pitch.
