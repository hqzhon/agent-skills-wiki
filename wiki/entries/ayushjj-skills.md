## When to use
When you want a small, portable engineering skill pack for Claude Code / Codex / Cursor—especially **harden** (prove a check can actually fail), premise-check before planning, specs before build, and careful batch ops—without adopting a huge plugin.

## What it does
Seven open Agent Skills: `premise-check`, `creating-specifications`, `harden`, `executing-batch-operations`, `prompt-engineering`, `autonomous-batch` (Claude Code only), and `plain`. Includes evals on some skills, a build-your-own write-up for session wrap/catch-up, and pointers to mattpocock/skills, Every compound-engineering, and pstack `correct`.

## Recipe / links
- Repo: https://github.com/ayushjj/skills
- Install: `npx skills add ayushjj/skills` (or `--skill harden`)
- Claude plugin: `/plugin install ayushjj-skills --marketplace ayushjj/skills`

## Why it made the cut
Concrete one-command install + named SKILL.md recipes with clear “when”; author publishes primary skills they use daily; MIT and multi-agent format.
