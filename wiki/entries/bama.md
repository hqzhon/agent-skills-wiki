## When to use
When you want a coding agent to **clone or invent a native macOS app** (Swift / SwiftUI / SwiftData): screenshot every screen, write milestone user stories, then build one story per commit with light/dark snapshots and tests—without living in the Xcode GUI.

## What it does
21 Agent Skills routed by `/bama`: `clone`, `user-stories`, `swift-swiftui`, `os-integrations`, `mac-design`, `design-system`, `layout-grid`, `build-and-verify`, `test-mac-app`, `improve-loop`, etc. Includes starter specs under `specs/` (window snapper, clipboard, launcher, …). Requires macOS 26+ / Xcode toolchain; `clone` on native apps needs computer-use.
