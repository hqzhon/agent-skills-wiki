## When to use
When agents keep producing **PPT 式幻灯片视频**（标题→照片→淡入），而你要的是 opener / promo / bumper / kinetic typography / explainer——在浏览器里做成片感动效，单文件 `index.html` 输出。

## What it does
Agent skill（+ Claude Code plugin）用 HTML + CSS + GSAP（必要时 Three.js）搭电影感 motion graphics；附 references、assets starters、scripts，可走 web 渲染或桥接到 AE。触发词覆盖 promo / opener / kinetic typography / explainer 等，即使用户没说 “motion graphic”。
