## When to use
要让 Claude Code / Codex / Cursor 等 agent 按同一套品牌档案，做本地商家或服务型业务的获客：定位、SEO / AI 搜索可见性、落地页与文案、广告与追踪、邮件和内容拆分。先跑 `start-here` 摸清业务，再按它给出的下一条技能走，而不是从零写提示词。

## What it does
32 个互相关联的营销技能，全部读写同一组品牌文件：你改过的内容会变成下一轮的检查项。按顾客接触顺序分组：

- 起步：`start-here`（约 3 分钟读站点与评价、写品牌档案并分流）、`brand-voice`、`positioning-angles`、`audience-research`、`competitive-intel`
- 被找到：Google 商户资料、本地 SEO 计划、服务区域页、AI 搜索可见性、站点审计、关键词与 SEO 内容、程序化 SEO
- 被选中：评价回复、手机首屏检查、落地页、直效文案、获客磁石
- 把电话打进来：付费广告、Google Ads 追踪、广告增量检验、Meta 广告 API、未接来电跟进、创意
- 把人带回来 / 赢客户 / 自我营销：邮件序列、newsletter、效果复盘、找本地客户、修复型开发信、社交内容、长文、内容原子化

README 写明每个技能都能在不付费工具的前提下工作。作者另外提供 playbook、获客产品和咨询，那些是可选的，不是运行这 32 个技能的前提。
