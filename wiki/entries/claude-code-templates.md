## When to use
想给 Claude Code 一次性挑装现成组件（skills、subagents、slash commands、hooks、MCP、settings），又不想从各个 awesome 列表手动复制；适合按领域（开发、科研、安全、生产力、营销）挑选。

## What it does
开源注册表 + CLI：按类别收录 900+ skills 及 agents / commands / hooks / MCP 配置，可浏览后用命令行装进项目或用户级 `.claude/`。

## Recipe / links
- Repo: https://github.com/davila7/claude-code-templates （MIT）
- 用法：按 README 用 CLI（`npx claude-code-templates@latest`）浏览并安装所需组件；建议挑单个 skill 装，先读其 SKILL.md 再用
- 同帖还列了 [agentic-awesome-skills](agentic-awesome-skills.md)（已收录）

## Why it made the cut
大型、活跃、MIT 的可安装注册表，有 CLI 和分类；作为「找 skill」入口价值高。注意质量参差，按需单装。
