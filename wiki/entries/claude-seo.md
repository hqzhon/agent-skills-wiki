## When to use
When you want a full SEO agency pass inside Claude Code: technical crawl/index/speed, E-E-A-T content gaps, Schema, AI-search citation readiness (GEO/AEO), plus local and e-commerce checks—ending in a prioritized action plan.

## What it does
Claude Code marketplace plugin: up to ~17 specialist agents fan out for a ~10–15 minute audit. Commands center on `/seo` (setup, audit, local, maps, backlinks, ecommerce, etc.). Optional extensions hook live SEO data sources.

## Recipe / links
- Repo: https://github.com/AgriciDaniel/claude-seo (~21.5k★, MIT)
- Install in Claude Code:
  - `/plugin marketplace add AgriciDaniel/claude-seo`
  - `/plugin install claude-seo@agricidaniel-claude-seo`
  - `/seo setup`
- Then `/seo audit <url>` (or other `/seo` commands)
