## When to use
需要把酷安社区里分散的玩机、刷机、Root / KernelSU、Termux、Docker 自托管、NAS / Homelab 或排错经验，交给 agent 当「有证据边界的知识技能」来查，而不是去翻原帖或把采集数据塞进上下文。

## What it does
把社区技术资料脱离个人身份后，整理成 `SKILL.md` + `references/` 技能库。本轮核到仓库树里有 139 个 `SKILL.md`（发帖称 177，以仓库为准），覆盖 Android 刷机与模块、端侧 AI / Termux、Docker 自托管、NAS / OpenWrt、云主机面板等。仓库明确：不分发原帖正文、评论、用户资料或采集库；技能会标注证据边界，社区经验不等于本库实机复现。欢迎用自己的话投稿并附公开来源，不要提交原始帖子或凭据。

## Recipe / links
- Repo: https://github.com/LIghtJUNction/coolapk-skills（1★，MIT）
- 按需把 `skills/<slug>/`（含 `SKILL.md` 与 `references/`）拷进 agent 的 skills 目录
- 示例：`skills/docker-self-hosted-app-cases/SKILL.md` 汇总 HivisionIDPhotos、ThingsBoard、Jitsi、MediaCMS 等容器部署案例，并写明命令与镜像版本未在本库复现

## Why it made the cut
可安装的中文技能包，场景清楚（玩机 / 自托管 / 排错），许可证和证据边界写得明白。仓库很新、星数很少，内容是整理后的社区案例而非全部实机验证，先观察维护与纠错。
