## When to use
When you need an agent to draw **architecture / flow / sequence / org charts** (45 types) as a single **self-contained HTML + SVG** file that matches brand colors/fonts — without Mermaid-style “AI diagram slop.”

## What it does
Agent skill by Cathryn Lavery. Prompt in plain language → editorial diagram (no shadows, brand-aware). Can extract palette/type from a site, import Draw.io / Mermaid / Excalidraw, and export PNG/SVG. Ships as plugins for Claude Code, Codex, Cursor, Copilot, Factory, etc.
