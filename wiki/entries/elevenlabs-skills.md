## When to use
When a coding agent should build or migrate **voice / TTS / STT / realtime conversation / dubbing / SFX / music** flows against ElevenLabs APIs without inventing endpoints or SDK shapes.

## What it does
Official Agent Skills pack (`elevenlabs/skills`): text-to-speech, speech-to-text, speech-engine, **realtime** (new agents or migrate OpenAI Realtime browser apps), conversational agents, sound-effects, music, voice-changer, voice-isolator, dubbing, plus onboarding / setup-api-key. Needs `ELEVENLABS_API_KEY`.
