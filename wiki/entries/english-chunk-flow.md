# english-chunk-flow（英语精听块课）

**Tags:** english, listening, education, multilingual, skill

**Engagement:** MIT · tests bundled · multi-host install docs

## When to use
When you want **intensive English listening lessons** from text, topic, or audio+transcript: sentence-level grammar chunks, contextual translations (zh/ja/ko/ar/es/pt/de/ru/en), replay, and saved hard segments—not exam scoring or live meeting ASR alone.

## What it does
Portable agent skill (`$english-chunk-flow`) plus CLI (`scripts/lesson.py` / `run.py doctor`): host annotates; CLI validates and packages a playable `lesson.html`. Supports TTS on macOS/Linux and original-audio alignment paths.
