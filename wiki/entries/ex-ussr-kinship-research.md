## When to use
When an agent should do **evidence-first family-history research** across the former USSR / Russian Empire—church books, civil, military, deportation/repression files, unindexed scans—and keep every claim auditable.

## What it does
Agent Skill (`SKILL.md` + references): case intake, person/artifact/claim registers, historical jurisdiction model, name-variant matrices, source hierarchy, evidence statuses (`hypothesis` → `strongly-corroborated` / `contradicted`), identity resolution, audit script, final report. Instructions in Russian; agent replies in the user’s language. Python stdlib helpers for case init, artifact hashing, evidence audit, PDF build.
