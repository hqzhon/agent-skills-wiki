## When to use
Right after you (or an agent) **finish a task and apply corrections** — before the hard-won procedure disappears into chat history. Especially useful for Grok Bot / multi-agent setups where the same instructions get re-explained tomorrow.

## What it does
Packages Lauren Tan’s (SpaceXAI / Grok Bot lead engineer) advice — observe the agent, course-correct, then turn the result into a reusable skill — into a single extraction prompt. Flow: Completed Task → Your Corrections → Reusable Skill → New Example → Verified Result.

## Recipe / links
1. Finish a real task with an agent and correct it as needed
2. In that completed conversation, run the extraction prompt (see post video / thread)
3. Review the generated skill file
4. Test it on a **different** example before trusting it
5. Bookmark the prompt for the next finished task
