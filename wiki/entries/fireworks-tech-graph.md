## When to use
When you need an agent to produce **precise SVG technical diagrams** (architecture, UML, cloud, agent/workflow) and export **PNG / offline HTML / GIF** — not photos, raster art, or statistical charts. Complements [Diagram Design](diagram-design.md) (editorial HTML+SVG); this pack is style-matrix + validate/render/check CLI.

## What it does
Portable Agent Skill (`SKILL.md`) with Python `scripts/fireworks.py`: generate/validate JSON → SVG, composition checks, PNG/HTML export, semantic SVG → GIF. Styles 1–12 (Flat Icon default; C4/cloud/event/observability contracts for 9–12). Warns that style templates do not replace checking topology.
