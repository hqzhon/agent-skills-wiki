# Forest Collage（森林手账拼贴）

**Tags:** design, collage, xiaohongshu, instagram, skill
**Source:** [@dou_jie29918](https://x.com/dou_jie29918/status/2114656484755984681) · 2026-10-26
**Engagement:** discovery post (low); brand-new repo with full SKILL.md + scripts

## When to use
When you want an agent to turn a handful of personal photos into a 3:4 forest-scrapbook collage for Xiaohongshu / Instagram—overlaps, soft double exposures, cut-outs, hand-drawn vines—instead of a flat grid.

## What it does
Agent Skill with 10 layout templates (A–J), measure → 3 layout sketches → render → lint workflow. Scripts handle face/subject measurement and rendering; the model owns aesthetic judgment. Ships `SKILL.md`, `scripts/` (`setup.sh`, `analyze.py`, `collage.py`, `lint.py`), templates, and examples.
