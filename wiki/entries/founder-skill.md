# founder-skill（创业压力测试包）

**Tags:** startup, evaluation, founder, skill-pack, claude
**Source:** [@ArthurLiu0725](https://x.com/ArthurLiu0725/status/2115397287665094956) · 2026-10-28
**Engagement:** ~2.1k★ · MIT · 11 skills + Python tools

## When to use
When you have a **business idea to pressure-test before spending money**—want a board vote, competitor map, simulated buyer panel, pricing, offer stack, unit economics, marketing plan, brand brief, ops, launch runbook, then one compiled plan with a verdict.

## What it does
Eleven Claude skills that chain through a `founder/` folder: board (Hormozi/Thiel/Jobs **framework lenses**, not impersonation) → competitors → 100 buyer agents → pricing → offer → CFO → marketing → brand → ops → launch → plan (`Profitable` / `Not yet` / `Incomplete`). Install as plugin or copy `skills/founder-*`.
