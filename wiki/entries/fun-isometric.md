## When to use
When you need **playful animated isometric stickers** (icons, empty states, onboarding art) with thick outlines, extruded slabs, named motion presets, and alpha video/canvas export—without hand-keyframing in After Effects.

## What it does
Agent skill `/fun-isometric`: object description → isometric sticker with facing (4 views), palette sets or brand colours, and AE-grade motion presets (hop/toss/wiggle/drift…). Live canvas replay + looping alpha video export (Bun/ffmpeg/Playwright).
