## When to use
When a vague product/idea needs grilling into a concrete plan — you want a live decision tree (open / settled / dropped) instead of a wall of text interview.

## What it does
Turns Matt Pocock’s `/grill-me` pattern into a visible live tree: blue = open questions, green = settled decisions, red = dropped (with children). Runs as a Node skill for Claude Code, Codex, Cursor, or any agent that can run Node.

## Recipe / links
- Install: `npx skills add AnasSahel/agent-labs --skill grill-me-live`
- Invoke: `/grill-me-live` plus your idea
- Code: https://github.com/AnasSahel/agent-labs/tree/main/skills/grill-me-live
