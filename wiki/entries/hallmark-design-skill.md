# Hallmark — Anti-Generic Website Design Skill

**Tags:** design, frontend, themes, claude-code, cursor, nutlope
**Source:** [@RoundtableSpace](https://x.com/RoundtableSpace/status/2114035439250153529) · 2026-10-24
**Engagement:** 168 likes / 19 reposts / 22 replies / 205 bookmarks

## When to use
When AI-built landing pages all look the same and you want the agent to apply **real design themes** plus automated checks that flag “made by AI” tells.

## What it does
MIT-licensed design skill (by @nutlope / Together) with 48 themes, pages oriented around visitor intent, and a lint that renders at multiple widths and flags machine-made patterns. Works with Claude Code, Codex, Cursor, and OpenCode.

## Recipe / links
- Repo: https://github.com/Nutlope/hallmark
- Install: `npx skills add nutlope/hallmark -g`
- Open Claude Code or Cursor in your project
- Run `/hallmark` with a short site description

## Why it made the cut
Installable recipe, clear trigger, strong community signal, and a public repo with documented themes + lint.
