## When to use
When Codex / Claude Code should **edit real footage into reels/Shorts**—cut dead air, flag mistakes, plan story, captions, B-roll, motion graphics—using Nate Herk’s HyperFrames-based playbook.

## What it does
**15 skills** mirrored for Claude Code and Codex (`.claude/skills/` + `.agents/skills/`): silence/mistake cutting, short-form edit, storytelling, HyperFrames/GSAP, motion showreel, style library, website-to-HyperFrames, etc. Includes editing playbook, 406 motion-graphics draft cards, scene templates, transcription helpers, and demos that need no paid API for the starter path.

## Recipe / links
- Repo: https://github.com/nateherkai/herk-edit-kit (~2.2k★)
- Install: `git clone` → `npm ci` → `npm run setup` → `npm test` (Node 22+, FFmpeg, Chrome/Chromium)
- Demo: `npm run demo` then HyperFrames lint/preview/render
- Optional: ElevenLabs / Whisper / Kie.ai per `docs/TOOLS-AND-API-KEYS.md`

## Why it made the cut
Full skill-pack with mirrored SKILL.md paths, measured house style, and agent-edited example reels—not a single vague “edit my video” prompt.
