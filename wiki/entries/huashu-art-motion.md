## When to use
When you want an agent to **code** cinematic / art-style motion (Canvas/SVG + ffmpeg/Playwright) instead of gambling on video-model frames — explainers, stylized shorts, parametric loops.

## What it does
Huashu art-motion skill: ~36 art styles, 9 narration grammars, parametric clip recipes, and reference code for voiced full pieces. Agent writes deterministic animation code; local render path typically needs `uv` + ffmpeg + Playwright Chromium (per README).
