## When to use
When you want an agent to ship **deliverable design** from one prompt: clickable App/web prototypes, editable PPTX, product-launch motion, or print-grade infographics — without generic purple-gradient AI look.

## What it does
Huashu Design 3.0 skill pack (`alchaincyf/huashu-design`). Six thumbnails → pick three full drafts; 84 style presets with sample sheets; brand-asset reading (logo/palette/UI shots); design-fact checklist + appearance ledger so projects don’t all look the same. Agent-agnostic (Claude Code / Cursor / Codex / OpenClaw / Hermes).
