## When to use
受不了编码 agent **先客套、再铺垫、最后才给结论** 的长回复时使用。它把输出改成「行动先行、步骤编号、去掉 Hope this helps!」的 ADHD 友好格式，适合日常写代码、查问题、要步骤说明。

## What it does
一个可装的 coding-agent skill / plugin。核心约定是：先给可用的答案或补丁，再用短列表列出步骤；禁止把关键信息埋进开场白。仓库提供多语言 README，以及 `AGENTS.md` / `INSTALL.md` 安装说明，并带 Claude Code / Codex 等插件清单。作者强调：这是输出风格技能，不是医疗建议。
