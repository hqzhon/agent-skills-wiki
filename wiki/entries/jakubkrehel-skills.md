# jakubkrehel/skills（Interface Skills）

**Tags:** design, a11y, typography, ui-ux, skill-pack
**Source:** [@Bee_Bombshell](https://x.com/Bee_Bombshell/status/2115650350787219471) · 2026-10-29
**Engagement:** ~9.0k★ · MIT · UI / type / color / a11y / layout / writing pack

## When to use
When an agent-built interface needs a **ranked review or polish pass** across accessibility, typography, color, layout, product writing, and UI detail—or you want focused skills (`better-typography`, `better-accessibility`, …) instead of one vague “make it pretty” prompt.

## What it does
Collection of Agent Skills from Interfaces / jakub.kr writing: `better-interface` (full ranked report), `better-ui`, `better-typography`, `better-colors`, `better-accessibility` (WCAG 2.2), `better-layout`, `better-writing`, plus user-invoked `interface-review`, `explain-interface`, `break`, `build-design`, `teardown`, `state-machine`, `variant`.

## Recipe / links
- Repo: https://github.com/jakubkrehel/skills (~9.0k★, MIT)
- Install: `npx skills add jakubkrehel/skills`
- Claude Code plugin: `/plugin marketplace add jakubkrehel/skills` then `/plugin install interfaces@interfaces`
- skills.sh: https://skills.sh/jakubkrehel/skills

## Why it made the cut
Concrete SKILL.md set with clear scenarios, one-command install, and a public MIT pack—meets recipe + use-case + verifiable repo.
