## When to use
用 Claude Code / Codex / Cursor 等 40+ 支持 Agent Skills 的工具，想要一套作者日常跑通过的中文工作流技能：把模糊想法定成目标、做完活整理文档与记忆、研究一个产品/公司、用固定口吻写公众号长文、清理磁盘。

## What it does
6 个技能：
- **leader**：把一句模糊想法定义成清晰目标，让 AI 拿着跑几个小时到完成
- **neat-freak**（`/neat`）：收工后对齐项目文档、CLAUDE.md、Agent 记忆，并审计规则是否被执行
- **hv-analysis**（横纵分析法）：对产品/公司/概念出万字 PDF 研究报告
- **khazix-writer**：按作者口吻和节奏写公众号长文
- **storage-analyzer**：扫描整机磁盘，三色分级给清理建议，网页一键移废纸篓
- **aihot**：免 Key 拉取 aihot.news 每日 AI 资讯

## Recipe / links
- 仓库：https://github.com/KKKKhazix/khazix-skills
- 安装：对 agent 说「帮我安装这个 skill：https://github.com/KKKKhazix/khazix-skills/tree/main/<skill-name>」，或把整个技能目录（含 `references/`、`scripts/`、`assets/`）放进 agent 的 skills 目录
- 只粘 SKILL.md 不够，需保留配套脚本；storage-analyzer 会动本机文件，先读脚本
