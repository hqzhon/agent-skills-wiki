## When to use
要把品牌简报做成 SVG 标识方案，再选出一款并导出套件（favicon / 应用图标 / 规范）时用。参考库里的 1,400+ 真实标识只供学习结构、对照品类惯例、避免撞车，文档写明不要复制。和 [ip-as-logo](ip-as-logo.md)（极简 IP 吉祥物、严格复杂度预算）不是同一条路径。

## What it does
把 agent 按标识设计流程来用：发现与 brief、选标志类型、几何构造与光学修正、色彩/字体/锁式、测试与交付。附不依赖外部服务的 Python 工具：按原则审计 SVG、概念总览与测试页（16px、单色、反相、斜视、镜像、场景与竞品架），以及演示板和 PNG / web manifest 导出。
