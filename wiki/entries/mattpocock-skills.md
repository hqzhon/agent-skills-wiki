## When to use
When you want a **small, composable set of day-to-day engineering agent skills** (align, grill, process helpers) rather than a heavyweight multi-agent framework that owns your whole workflow.

## What it does
`mattpocock/skills` — “Skills for Real Engineers,” taken from Matt’s own `.agents` directory. Packaged for Claude Code / Codex / Copilot plugins and [skills.sh](https://skills.sh/mattpocock/skills). Emphasizes short, adaptable skills over long locked-in processes (contrasts with GSD/BMAD/Spec-Kit style ownership).

## Recipe / links
- Repo: https://github.com/mattpocock/skills (~303k★)
- Claude: `claude plugin install mattpocock-skills@claude-plugins-official`
- Or copy via skills.sh; don’t install both plugin + copy or you duplicate skills
- Skill folders under `skills/` (`engineering`, `productivity`, …); read `SCOPE.md` / `AGENTS.md`

## Why it made the cut
Massive verified skill library with clear install paths and an explicit “composable small skills” philosophy; surfaced again in this hour’s feed.
