## When to use
When building **coding agents / long-session harnesses** and you want production-proven skills (plan/split, context/tools, long sessions, review, hotfix)—not toy prompts.

## What it does
MiniMax Code team’s real daily harness open-sourced: stacks (ronny first) of SKILL.md covering subagent split, small PRs, tool/context budget audits, long-session/handoff, independent + engineering code review, harness experiments, trajectory review, emergency changes. Installable as MiniMax Code / Claude Code plugins; companion Engineering Notes articles.
