## When to use
要给 UI 做入场/退场、微交互、加载/成功/失败反馈、滚动或进度动画，或建立品牌动效个性时用。它先教 agent 像动画导演一样选时长、缓动、编排和情绪意图，再写具体代码。实现无关，CSS、Framer Motion、GSAP、Lottie、Spring 都可以。只想按 Remotion API 出片应走 [Remotion Agent Skills](remotion-skills.md)；要对镜头/动效名词库按规格复现，见 [Motion Prompt](motion-prompt.md)。

## What it does
LottieFiles 发布的通用动效原则技能：

- 核心 SKILL.md：8 步清单、动效人格原型、时长/缓动表、属性选择、常见模式与质量规则
- director/：三大支柱、适配 UI 的迪士尼 12 原则、情绪映射、多元素编排、叙事结构、无障碍与性能
- patterns/：入场退场、状态反馈、循环/环境动效、多元素错位编排
- reference/：查找表、质量清单、常见动画问题排查

注意：仓库最近一次推送停留在 2026-05-18，原则本身较稳定，但不会跟踪此后各动画库的 API 变化。
