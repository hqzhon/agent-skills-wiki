## When to use
用 [egoist/mygo](https://github.com/egoist/mygo)（Go 原生桌面 UI + webview）写/改应用时：窗口与状态、组件选型、桌面服务、Web 前端绑定、动效、自定义绘制。不要用于非 MyGo 的 Electron/Tauri 项目。

## What it does
六个标准 `SKILL.md`：`mygo-usage` / `mygo-components` / `mygo-desktop` / `mygo-web` / `mygo-motion` / `mygo-drawing`。互相对相对路径引用，宜整包安装。

## Recipe / links
- 仓库：https://github.com/transmit-bug/mygo-skills
- 安装：`npx skills add transmit-bug/mygo-skills`
- 示例单技能：`npx skills add transmit-bug/mygo-skills --skill mygo-components`

## Why it made the cut
可安装配方 + 明确框架边界；skills.sh 可验证。星数低、垂直场景，但 SKILL 完整。
