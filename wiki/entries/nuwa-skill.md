## When to use
When you want an agent to **distill how someone thinks** (mental models, decision heuristics, expression DNA, anti-patterns, honest limits) from books/interviews/articles into a runnable person-perspective skill—not a shallow “you are X” roleplay.

## What it does
Meta-skill `huashu-nuwa`: named person or fuzzy need → research → framework extraction → write a character `SKILL.md` with sources and research notes. Separates the subject’s words, others’ takes, and model inference. Works across Claude Code, Codex, Cursor and other Agent Skills hosts.
