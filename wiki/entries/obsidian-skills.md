## When to use
When an agent should work **inside an Obsidian vault** using Obsidian CLI and open formats (Markdown, Bases, JSON Canvas) instead of inventing ad-hoc vault conventions.

## What it does
Official-adjacent skill pack from Obsidian’s CEO (kepano): skills for Obsidian CLI, Markdown, Bases, JSON Canvas, Defuddle, and related vault workflows. Agent Skills–spec compatible (Claude Code, Codex, Open Code, etc.).

## Recipe / links
- Repo: https://github.com/kepano/obsidian-skills (~50k★)
- Install: `npx skills add https://github.com/kepano/obsidian-skills` or Claude marketplace `kepano/obsidian-skills`
