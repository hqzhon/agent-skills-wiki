## When to use
When an agent should work **inside an Obsidian vault** using Obsidian CLI and open formats (Markdown, Bases, JSON Canvas) instead of inventing ad-hoc vault conventions.

## What it does
Official skill pack in the Obsidian org (obsidianmd/obsidian-skills); it was started by CEO kepano and the old kepano/obsidian-skills URL now redirects here. Skills cover Obsidian CLI, Markdown, Bases, JSON Canvas, Defuddle, and related vault workflows. Agent Skills–spec compatible (Claude Code, Codex, Open Code, etc.).

## Recipe / links
- Repo: https://github.com/obsidianmd/obsidian-skills (~52.3k★, MIT；kepano/obsidian-skills 会重定向到这里)
- Install: `npx skills add https://github.com/obsidianmd/obsidian-skills` or Claude marketplace `obsidianmd/obsidian-skills`
- Skills under `skills/` (`obsidian-cli`, `obsidian-markdown`, `obsidian-bases`, `json-canvas`, …)
- Roundtable also listed community second-brain repos; treat those separately and read licenses before install
