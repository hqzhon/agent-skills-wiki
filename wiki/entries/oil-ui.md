## When to use
When an agent should **设计 / 改进 / 评审**网站、App、后台或组件界面：探索真正不同的方向、生成多风格同屏对比页，再对着真实截图打磨——而不是三套同布局只换配色。

## What it does
Host-neutral UI design skill: product facts → design north star → distinct directions → side-by-side comparison page → screenshot-based refine. Explicitly refuses pure business logic, API work, or already-specified micro edits. Optional Python comparison-page generator; showcase at ui.oiloil.org.
