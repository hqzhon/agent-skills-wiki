# OpenMontage（开源 Agent 视频制作系统）

**Tags:** video, production, pipeline, skill-pack, multi-agent
**Source:** [@FreedomAIG](https://x.com/FreedomAIG/status/2116880117507244479) · 2026-11-02

## When to use
要让 Claude Code / Codex / Cursor 这类编程 Agent 用自然语言完成整支视频：调研、写脚本、生成素材、剪辑、合成，或者「贴一个你喜欢的视频」让它复刻风格。

## What it does
把编程助手变成视频工作室：12 条制作流水线、100+ 工具、700+ 个 agent skill 与制作知识文件。Agent 按 `AGENT_GUIDE.md` 选流水线、调用素材 / 配音 / 合成工具，产出最终成片；Provider 可替换（见 `docs/PROVIDERS.md`）。
