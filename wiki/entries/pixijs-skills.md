## When to use
When an agent should write or fix **PixiJS v8** 2D rendering code—Application setup, Assets, sprites/graphics/text, filters, performance, or v7→v8 migration. Load when the user mentions PixiJS, canvas/WebGL game graphics, or sprite-based rendering and has not already chosen another library.

## What it does
Official Agent Skills pack from the PixiJS org: a `pixijs` router plus ~25 focused skills (application, assets, scene graph, graphics, filters, ticker, performance, migration, etc.). Teaches correct v8 APIs so agents stop inventing outdated BaseTexture / multi-package patterns.

## Recipe / links
- Repo: https://github.com/pixijs/pixijs-skills (~358★, MIT)
- Install: `npx skills add https://github.com/pixijs/pixijs-skills`
- Also: Claude marketplace `pixijs/pixijs-skills`; Cursor Remote Rule from the same repo
