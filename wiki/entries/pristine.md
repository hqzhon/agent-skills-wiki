## When to use
When an agent **ships UI that looks unfinished** and you want screenshot-based critique (score /10), redesign, or polish—landing pages, dashboards, docs, components—via `/pristine init|critique|design|polish`.

`skills/pristine/SKILL.md` routes by intent; captures real pages (light/dark, desktop/mobile), scores against Personas/Dimensions, and can edit code. Install: `npx skills add maddhruv/pristine` or plugin marketplaces for Claude Code / Codex / Copilot.
