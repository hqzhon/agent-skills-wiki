## When to use
When asked for a **product launch film / UI motion reel / Dribbble-style launch video** from a website URL or product brief—cursor-driven morphing UI, springs, beat-synced SFX, 60 fps—without hiring After Effects.

## What it does
Claude Code skill encoding Chan’s creative direction (one shape never cuts, blur content swaps, springs, real data, logo slams) plus a seek(t) / Playwright subframe / ffmpeg tmix / numpy beat-grid render pipeline. Outputs MP4 from HTML motion.
