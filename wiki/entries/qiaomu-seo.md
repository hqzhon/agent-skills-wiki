## When to use
When an agent should **审计 / 诊断 / 规划 / 修复网站 SEO**：收录异常、自然流量下滑、关键词无落地页、canonical/sitemap/robots、站点迁移、国际化 / 电商 SEO，或 AI Search（AI Overviews、ChatGPT Search、Perplexity）可见性基础检查——用户给出 URL、代码、Search Console 导出或 crawl 数据时加载。

## What it does
Professional SEO Agent Skill for Claude Code / Cursor / Codex. Works along the real search chain (crawl → render → indexability → canonical → intent → internal links → measurement). Outputs prioritized findings with observed / inferred / missing-evidence labels; audit modes are read-only unless the user authorizes edits. Explicitly refuses ranking guarantees and unsupported metrics.
