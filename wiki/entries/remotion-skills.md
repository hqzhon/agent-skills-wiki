## When to use
When an agent should **create, edit, caption, map-animate, preview, or render Remotion videos** in React—new compositions, markup/best practices, Studio preview, render, maps, captions, SaaS architecture, docs lookup, or upgrades. Load when the user mentions Remotion, React video, or programmatic motion graphics.

## What it does
Official Agent Skills pack from the Remotion org: a `remotion-best-practices` router plus focused skills (`remotion-create`, `remotion-markup`, `remotion-studio`, `remotion-render`, `remotion-maps`, `remotion-captions`, `remotion-saas`, `remotion-interactivity`, `remotion-docs`, `remotion-upgrade`, `remotion-multimedia`). Teaches agents to write real Remotion React code instead of inventing APIs.

## Recipe / links
- Repo: https://github.com/remotion-dev/skills (~5.7K★)
- Install: `npx skills add remotion-dev/skills`
- Docs: https://www.remotion.dev/docs/ai/skills
- Also: `npx remotion skills add` / `gh skill install remotion-dev/skills`

## Why it made the cut
Official library-maintained skill pack with concrete when-to-use routing, installable SKILL.md set, public GitHub repo, and clear install path—not a tip thread. Note Remotion’s license: free for individuals / companies ≤3 employees; larger orgs need a company license.
