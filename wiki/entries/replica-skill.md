# Replica Skill（11 步复刻 App）

**Tags:** product, reverse-engineer, fullstack, skill-pack, claude-code
**Source:** [@Stargridcompass](https://x.com/Stargridcompass/status/2115088629890789565) · 2026-10-27
**Engagement:** ~10 bookmarks · ~1k impressions on ZH post · repo ~6063★ · MIT

## When to use
When you want an agent pipeline to **clean-room clone an app’s features/flows** (recon → architecture → design → build → backend → test → parity → brand → launch → deploy), and optionally mine store/community complaints into improvements—not to copy code, logos or copy.

## What it does
Eleven Claude Agent Skills (`replica-recon` … `replica-deploy`) that hand off via a `replica/` workspace. Entrepreneur skill turns user hate into fixes. Enforces clean-room boundaries in the skills themselves.

## Recipe / links
- Repo: https://github.com/Jakeschincariol/replica-skill (~6063★, MIT)
- Install: paste repo into Claude / `/plugin marketplace add Jakeschincariol/replica-skill` then install plugin; or copy `replica-*` folders into `.claude/skills/`
- Needs: Python 3.8+ for bundled tools (no pip deps)

## Why it made the cut
Large verifiable skill pack with install paths, ordered workflow, and strong community stars; clear product-rebuild use case beyond a single prompt.
