# Scenario Labs Skills（媒体 / DCC 生产技能包）

**Tags:** skill-pack, image, video, audio, 3d, game-art, mcp
**Source:** [@yaro360](https://x.com/yaro360/status/2118478633618567487) · 2026-11-06
**Engagement:** discovery post; repo scenario-labs/skills ~3.0k★ · MIT

## When to use
让 coding agent（Claude Code / Cursor / Codex 等）走 Scenario MCP 产出游戏与创意向的图片、视频、音频、贴图、天空盒、3D 资产，或在本机驱动 Blender / Maya / ZBrush / Unreal / Unity / Godot / Roblox 时。

## What it does
Agent Skills 格式的生产工作流：选型、报价后再花、角色与品牌一致性、storyboard / UGC / 字幕 / 质检门禁等；另有一套「专家工具」族，把 DCC / 引擎教程蒸馏成可本地调用的技能族（不依赖 Scenario 服务器）。按角色或目标分组安装。

## Recipe / links
- Repo: https://github.com/scenario-labs/skills
- 安装菜单：`npx skills add scenario-labs/skills`
- 单技能示例：`npx skills add scenario-labs/skills --skill scenario-image`
- MCP 文档：https://mcp.scenario.com/docs
- 按角色安装说明：仓库 `INSTALL.md`

## Why it made the cut
有完整可安装 SKILL 仓库与 MCP；场景清晰（媒体生产 + 本机 DCC）；MIT 可验证；社区星数与 docs 齐全。
