## When to use
When an agent must combine **code + external scientific data + validation** (literature review, single-cell pipeline, virtual screening, multi-omics, publication figures) rather than only write prose.

## What it does
Open Agent Skills pack covering bioinformatics/genomics, chemistry/drug discovery, proteomics, imaging, neuroscience, materials, geospatial, lab automation, and scientific communication. Each skill is a self-contained `SKILL.md` workflow for Claude Code, Codex, Cursor, and compatible hosts.

## Recipe / links
- Install collection: `npx skills add K-Dense-AI/scientific-agent-skills`
- Or one skill via `gh skill install K-Dense-AI/scientific-agent-skills <name>` (e.g. `scanpy`)
- Overview: https://spytechai.com/repos/scientific-agent-skills/
- Pin a release/commit; keep incompatible Python envs separate; read each SKILL.md; scan third-party skills before use
- Outputs are drafts for human expert review — not diagnoses or compliance decisions

## Why it made the cut
Large concrete skill pack with install commands, domain coverage list, security notes, and Agent Skills standard compliance.
