# scroll-craft（滚动驱动精品落地页）

## When to use
要做「滚动即时间轴」的精品品牌 / 产品落地页：分层 hero、视频 scrub、多页面语法、移动端单独构图，而不是同一套模板换皮。不要用于普通文档站或无滚动叙事需求的后台。

## What it does
完整 agent skill + Claude Code plugin：把 scroll 当 timeline，规划 page grammar / 情绪峰值 / signature move，生成语义 HTML 与可验证的桌面·移动·reduced-motion 滚动截图。内含 8 种页面语法、指纹门控与 verification harness；附带十个已过审沉浸式站点的制作流程参考。
