## When to use
When you want Claude Code / Cursor / OpenClaw-style agents to run end-to-end office workflows: deep research with citations, data analysis, infographic/PPT generation, HTML experiences, or proactive project tracking — especially alongside SenseNova models or free-model gateways.

## What it does
Open-source Agent Skills pack from OpenSenseNova. Each skill is a `SKILL.md` directory (agentskills.io). Flagship `sn-deep-research` orchestrates plan → parallel evidence → validation → cited `report.md` (quick/normal/heavy modes). Companion skills cover academic/code/social search, image & infographic generation, slide decks, Excel analysis, and HTML motion reports. Install by cloning into the agent's skills directory (see INSTALL.md).
