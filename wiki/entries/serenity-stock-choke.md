## When to use
做产业链研究时，想从下游需求反推上游瓶颈环节，筛出 A 股 / 港股 / 美股里可能受益的公司，并拿到一份结构化报告。

## What it does
把「供应链瓶颈」思路做成 agent skill：先判断行业所处阶段，再定位供应链关键环节，筛选候选公司，最后生成结构化报告。覆盖电力、光模块、半导体设备、军工、新能源车等领域；零依赖，Claude Code / Codex 等通用 agent 可用。

方法论明确、步骤可执行、有完整仓库；与已收录的 InvestSkill、hithink-finance 互补，专注产业链瓶颈视角。仅作研究框架，不构成投资建议。
