## When to use
When you want a coding agent to **在本机出片**（motion graphics、口播、配乐、音效、字幕、剪辑、平台导出），不要云端视频 API / 上传素材。

## What it does
Local video studio skill pack: one-sentence brief → agent directs → machine renders; optional studio mode (concept / look / music / storyboard before render); built-in `showtime qa` gate before delivery. Works with Claude Code plugin path or `npx skills add`.

## Recipe / links
- Repo: https://github.com/FavioVazquez/showtime (~306★, MIT)
- Claude Code: `/plugin marketplace add FavioVazquez/showtime` then `/plugin install showtime@showtime`
- Other agents: `npx skills add FavioVazquez/showtime`
- Skills under `skills/`; no API keys required for core local path

## Why it made the cut
Installable Agent Skills pack with local-first pipeline and QA step—distinct from Remotion-only packs already in the wiki.
