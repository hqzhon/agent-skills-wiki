## When to use
When producing **Chinese AI short dramas**: estimate runtime from reading speed while writing, split per-character dialogue, and move from novel → outline → characters/art/script → staging → storyboard with quality gates.

## What it does
Seven agent-agnostic skills under `skills/*/SKILL.md` (novel-outline, novel-characters, novel-art, novel-script, novel-staging, novel-storyboard, character-refs), each with zero-dependency Node scripts as gates. Works with Claude Code and Codex.
