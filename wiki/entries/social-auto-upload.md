## When to use
When an agent should upload video, article, or image posts to Douyin, Xiaohongshu, Channels, Bilibili, YouTube, TikTok, Zhihu, Weibo, and related platforms through a unified CLI + skills—not one-off browser macros.

## What it does
Open-source multi-platform publisher with `sau` CLI and 18 platform Skills (`douyin-upload`, `bilibili-upload`, `xiaohongshu-upload`, `youtube-upload`, `tiktok-upload`, …) plus a cross-platform entry skill. Supports scheduled posts on some platforms; still requires account login and per-platform field limits.

## Recipe / links
- Repo: https://github.com/dreammis/social-auto-upload (~15.8k★)
- Install one skill: `npx skills add dreammis/social-auto-upload --skill douyin-upload`
- skills.sh (Douyin): https://www.skills.sh/dreammis/social-auto-upload/douyin-upload
- Skill map: `skills/*/SKILL.md` in-repo

## Why it made the cut
Concrete SKILL.md pack + install path; clear multi-platform publishing use case; large verifiable community signal on the underlying tool.
