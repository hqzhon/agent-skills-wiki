## When to use
要让 agent 做社媒调研时用：找超过账号基线的爆款、挖评论里的问题与反对意见、拆竞品内容策略、看 Meta / Google / LinkedIn 广告库、追趋势或做创作者名单。数据经 [ScrapeCreators](https://scrapecreators.com) API，需要 `SCRAPECREATORS_API_KEY`（商业接口，有配额和费用）。不要把它当成无需账号的公开爬虫，也不要用它发帖或管账号。

README 覆盖的平台以 TikTok、Instagram、YouTube、Reddit、X、LinkedIn、Facebook、Threads、Bluesky、Pinterest、Rumble 及广告库为主。本窗中文介绍帖写了抖音/小红书/B 站/微博/知乎，以仓库 README 为准，不把未写明的平台算进能力范围。若主要做中文平台近 30 天讨论，见 [last30days-cn](last30days-skill-cn.md)。

## What it does
一套完整调研工作流，而不是只把 API 转给模型。技能包括：`outlier-post-finder`、`transcript-intelligence`、`comment-mining`、`competitor-social-research`、`ad-library-teardown`、`trend-discovery`、`influencer-prospecting`、`audience-research`、`social-listening-brief`、`product-demand-research`、`creator-profile-teardown`、`content-repurposing`，以及底层的 `scrapecreators-api`。
