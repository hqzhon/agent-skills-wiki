## When to use
要给落地页、功能卡、文档头图做「产品截图感」的插画或短动画：浏览器/App 窗口、Dashboard、手机、通知、终端、bento 网格、光标走查 demo，但不想贴真截图或画成线框图。

## What it does
`SKILL.md` 先给一条核心原则（像真产品、只保留观众需要的细节、有意图地取景、每个动作都有因），并列出五种失败形态（太满、线框、装盒、扁平、平淡）。附构图与动效指导、可直接抄的 React + CSS 组件套件、示例，以及把结果录成视频让 agent 自检的工具。
