## When to use
做历史叙事 / 人物故事类中文口播短视频，想让 Claude Code / Codex / Cursor 一次走完「选题 → 钩子 → 口播稿 → 配音 → 字幕对齐 → 分镜配图 → 剪映专业版草稿」，或只做其中某一步（只写稿、只改开头钩子、只拆镜生图、用现成素材出剪映草稿）。

## What it does
把短视频生产线打包成一个 Agent Skill：内置两套写作风格和 370+ 篇高赞文案对标库、3 套视觉画风与参考图库；配音可接豆包语音或自备音频，本地转录对齐时间轴；最终导出带关键帧推拉运镜和时间戳字幕、可继续编辑的剪映专业版草稿。工作流有开关，可按模块拼装。
