**Engagement:** discovery post (low); repo ~54★ · multi-harness Agent Skills

## When to use
When you need an evidence-backed second opinion on a startup idea—scorecard, assumption ledger, and shareable HTML report—not a one-shot ChatGPT take. Works across Claude Code, Codex, Cursor, and other Agent Skills hosts.

## What it does
Agent skill that runs 14 parallel dimension evaluators (pain, WTP, solution gap, founder-market fit, …), each with its own web search; merges into a weighted PIVOT/GO/STOP scorecard with letter-graded evidence. Extra commands: HN browse/analyze, improve (three rewrites), diff runs, share via gist.

## Recipe / links
- Repo: https://github.com/eph5xx/tweakidea (~54★)
- Install: `npx skills add eph5xx/tweakidea`
- Claude plugin: `/plugin marketplace add eph5xx/tweakidea` then `/plugin install tweakidea@tweakidea`
- Example: `/tweakidea evaluate "A mobile app that…"`
