## When to use
When the user runs `/ub-mode` or asks for disciplined engineering principles while writing or changing code—TDD, smallest honest change, complexity/duplication gates, mutation testing.

## What it does
A single `SKILL.md` that enforces **First Make it Work → Then Make it Right → Practice**: laziness protocol, TDD, redesign from first principles, then deterministic gates via companion tools (crapper CRAP < 10, dryer duplication, mutator, uml-viewer). Loosely derived from poteto-mode / pstack, reduced.

## Recipe / links
- Repo: https://github.com/unclebob/ub-mode (~433★)
- Install: copy `SKILL.md` to `ub-mode/SKILL.md` under the agent skills dir, invoke `/ub-mode`
- Companions: [crapper](https://github.com/unclebob/crapper), [dryer](https://github.com/unclebob/dryer), [mutator](https://github.com/unclebob/mutator), [uml-viewer](https://github.com/unclebob/uml-viewer)

## Why it made the cut
Concrete SKILL.md with clear trigger, ordered workflow, and verifiable companion quality-gate repos—not empty “write clean code” advice.
