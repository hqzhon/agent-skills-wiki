## When to use
When a coding agent should generate or retheme UI with **design-system intelligence**—product-type styles, palettes, typography, anti-patterns, and pre-delivery checks—across Claude Code, Cursor, Copilot, Codex, and many other assistants—not another component dump alone.

## What it does
AI skill + `uipro` CLI: design-system generator (192 product rules, styles, colors, fonts), BM25 search over design data, stack-specific guidelines (React/Next/Vue/Flutter/… ), and install targets for 20+ agents. Open-source core; Premium brand/asset tier sold separately (noted).

## Recipe / links
- Repo: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill (~140679★)
- CLI: `npm i -g ui-ux-pro-max-cli` then `uipro init --ai cursor` (or `claude`, `codex`, `all`, …)
- Claude: `/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill` then `/plugin install ui-ux-pro-max@ui-ux-pro-max-skill`
