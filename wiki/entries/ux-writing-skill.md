## When to use
要写或改产品界面上的文字时用：按钮、标签、错误/成功提示、表单、引导、空状态、帮助文案，或建立语气规范、审计现有文案是否一致。不要用它做整页视觉改版或可用性走查——那是 [ux-audit](ux-audit-skill.md)；也不要把它装到 ChatGPT 网页版（README 写明只适用于 Claude / Codex CLI 或 IDE / Cursor 这类能装 skill 的环境）。

## What it does
把 UX writing 做成可加载框架，而不是一份风格备忘录。四条质量标准：有目的、简洁、对话感、清楚；并带无障碍指引、句长/理解度等参考基准、错误文案模式和语气适配。参考材料按需加载。也可以让 agent 结合 Figma 稿审文案。
