# video-agent-skills（Melvynx 短视频工厂）

**Tags:** video, short-form, remotion, youtube, tiktok, skill-pack
**Source:** [@Manojkumar2257](https://x.com/Manojkumar2257/status/2115408560129818891) · 2026-10-28
**Engagement:** ~63★ · MIT · local render (Node + Chrome + ffmpeg + whisper.cpp)

## When to use
When you want Claude Code to turn a **raw phone/webcam take into a finished 9:16 short** (or longer YouTube cut)—script, edit, translate, audit Instagram, publish—without a SaaS editor.

## What it does
Skill pack: `/studio-setup`, `/short-editing` (silence cut, boards-on-word, captions, CTA, LUFS), `/studio-script`, `/outliers`, `/steal`, `/broll`, `/clips`, `/short-translate`, `/vox`, `/publish`, plus `/editing` router. Render engine runs on your machine.

## Recipe / links
- Repo: https://github.com/Melvynx/video-agent-skills (~63★)
- Install: `npx skills add Melvynx/video-agent-skills -a claude-code`
- README skills table documents each command

## Why it made the cut
Verifiable pack with local render path, clear install, and named skills for a full short-form pipeline—distinct from content-only YouTube packs already in the catalog.
