## When to use
想按官方团队或社区来源浏览、对比现成 Agent Skills（Claude Code、Codex、Cursor、Gemini CLI、Copilot、OpenCode 等），先从一份人工精选目录入手，而不是在零散仓库里逐个搜。

## What it does
VoltAgent 维护的 Awesome 列表：收录官方与工程团队实际在用的 `SKILL.md`，并按官方来源 / 语言与框架 / 社区技能分目录。仓库本身是索引（README 列出链接与安装路径约定），不是一键安装的技能包。README 含质量标准与安全提示；页面也有赞助位，发现后仍应逐个阅读上游 `SKILL.md` 再装。

与已收录的 [Agentic Awesome Skills](agentic-awesome-skills.md)（可安装合集 + AAS Core 检索/预览）互补：这里偏精选导航，那边偏本地目录操作。

## Recipe / links
- Repo: https://github.com/VoltAgent/awesome-agent-skills （~37.3k★，MIT）
- 按 README 的「Skills Paths」把选定技能装到对应 agent；不要把整个 awesome 仓库当 skill pack 安装
- 安装前可用 [SkillSpector](skillspector.md) 等工具扫描上游技能

## Why it made the cut
可验证的高星精选目录，使用场景清楚，和已有的可安装合集不重复。社区信号强；合集质量仍参差，且 README 有赞助内容，不能单靠目录标签代替审阅。
