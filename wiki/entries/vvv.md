# vvv（视频模板工厂）

**Tags:** video, remotion, templates, skill-pack
**Source:** [@GitTrend0x](https://x.com/GitTrend0x/status/2114681083308523617) · 2026-10-26
**Engagement:** roundup mention; repo ~389★ · Remotion kits + Agent Skill

## When to use
When you want to build a reusable Remotion video template once (wedding short, album reel, comedy opener, etc.) and have any coding agent pick the kit, place photos, write copy, render, self-check, and deliver—including rebuilding a reference clip with your footage as an editable project.

## What it does
Agent Skill + editable Remotion template kits. One-sentence prompts drive template selection, media placement, copy, render, and `vvv check`. Works across Claude Code, Codex, Cursor, Gemini CLI, Copilot, WorkBuddy, and 20+ agents; optional MCP for template browsing.

## Recipe / links
- Repo: https://github.com/actionow-ai/vvv (~389★)
- Skill: https://github.com/actionow-ai/vvv/tree/main/skills/vvv
- Claude Code: `/plugin install vvv --marketplace actionow-ai/vvv`
- Others: `npx skills add actionow-ai/vvv` (+ set `VVV_KIT` after clone)
- Local render needs Python 3.9+, Node.js 26, npm

Concrete skill + plugin install; clear template-reuse video use case; substantial open repo with kits, checks, and multi-agent docs.
